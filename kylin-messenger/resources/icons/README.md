# Icon Attributions

The icon set combines vector assets from the Feather Icons project (MIT License) with custom status presence badges generated in-house to match the application's palette. Feather icons used include `app_icon.svg`, `camera.svg`, `cpu.svg`, `file.svg`, `file-text.svg`, `message.svg`, `message-square.svg`, and `smile.svg`. Presence icons (`status_online.svg`, `status_away.svg`, `status_busy.svg`, `status_invisible.svg`, `status_offline.svg`) are derivative works based on Feather styling.
