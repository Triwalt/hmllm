# Qt Quick UI 与经典桌面版差异梳理

<!-- markdownlint-disable MD013 -->

> 更新时间：2025-11-15
>
> 目的：梳理 Qt Quick 预览界面当前能力与经典 Qt Widgets 桌面版之间的功能差异，为后续补齐与替换提供依据。

## 总览

| 区域 | 经典桌面版 | Quick 预览版 | 差异/缺失 |
| --- | --- | --- | --- |
| 导航结构 | `QTabWidget` 切换“在线用户/联系人/群组”，含状态栏/系统托盘 | 单一页面，仅显示在线联系人 | 缺少联系人/群组页、状态控制、托盘集成 |
| 在线联系人 | 分页展示、右键菜单、双击开启独立聊天窗 | ListView + 简单 delegate，点击后右侧显示对话 | 需补齐搜索、分组、上下文操作、多会话容器 |
| 联系人管理 | 搜索、分组过滤、添加/编辑/删除、持久化 | 无 | 需接入 `SettingsContactRepository`，实现 CRUD UI |
| 群组管理 | 列表、成员管理、群消息窗口 | 无 | 需模型 + UI + `NetworkManager` 群聊 API |
| 聊天体验 | 独立聊天窗、消息历史、状态标记、文件/表情/AI 按钮 | 单窗口右侧列表，仅文本气泡 | 缺多会话、消息来源过滤、附件/AI/通知等 |
| 文件传输 | 接收提示、保存对话、进度/完成通知 | 无 | 需监听 `fileOfferReceived` 等信号，提供 UI |
| AI 功能 | 快捷按钮（智能回复、AI助手、图像标注等） | 无 | 需提供触发入口及结果展示 |
| 状态与系统 | 下拉切换在线状态、编辑个性签名、系统托盘菜单 | 顶部仅显示“当前用户”与“刷新在线” | 需添加状态选择、签名编辑、通知托盘（或替代方案） |
| 设置/工具 | 菜单栏、工具栏、截图/日志/主题等入口 | 无 | 需规划统一的“更多”抽屉或设置页 |

## 关键依赖梳理

- **核心数据来源**：`NetworkManager`（在线用户、聊天、群组、文件）、`Core::Repositories::SettingsContactRepository`（联系人）、`Core::Repositories::MessageRepository`（历史消息）。
- **现有 Quick 层**：`QuickAppHost` 暴露 `QuickUserListModel` 与 `QuickMessageListModel`，只包含在线联系人和当前会话记录。
- **缺少的模型/接口**：
  - 联系人/群组列表模型（QAbstractListModel）。
  - 多会话消息模型（会话 -> 消息列表）。
  - 文件传输状态模型。
  - 状态/设置接口（切换在线状态、更新签名、偏好）。
  - AI 服务调用入口（需要 `IAIService` 注入 QuickHost 或提供桥接信号）。

## 建议分阶段落实

1. **架构扩展**
   - 为 `QuickAppHost` 引入服务定位器，暴露联系人/群组/状态接口。
   - 重构消息模型：区分“会话列表”与“消息列表”，支持多会话切换与历史加载。
   - 封装文件传输、AI 调用、状态切换方法，提供 `Q_INVOKABLE`。

2. **UI 布局升级**
   - 左侧：用户信息 + 状态控制 + Tab（在线/联系人/群组）。
   - 中间：会话列表 / 群组 / 联系人详情卡片。
   - 右侧：聊天区（消息、附件、AI 回复、输入区）。
   - 顶部/底部：工具栏（刷新、搜索、更多）与状态栏（通知、进度）。

3. **功能补齐**
   - 联系人 CRUD、群组成员管理、文件传输对话框。
   - AI 功能：智能回复建议区、AI 助手对话、图像标注弹层。
   - 系统通知/Toast、日志查看、主题切换。

4. **体验与一致性**
   - 对齐桌面版文案与交互流程（右键菜单、快捷键、双击逻辑）。
   - 引入深浅色主题、对齐 spacing/typography。
   - 添加空态、加载、错误反馈。

### 组件规划

| 区域 | 组件 | 说明 |
| --- | --- | --- |
| Header | `ToolBar + RowLayout` | 绑定 `QuickAppHost` 的本地用户信息、状态切换、搜索框；提供设置、主题、刷新按钮 |
| 左栏 | `NavigationDrawer` 或 `Pane` + `TabBar` | 乘载用户卡片、在线状态切换、Tab 切换（在线/联系人/群组），每个 Tab 对应不同模型 |
| 中栏 | `StackLayout` + `ListView` | 根据当前 Tab 展示列表（在线用户、联系人、群组），并在底部/右侧显示详情（群成员、备注） |
| 右栏 | `SplitView` 右侧 Pane | 顶部显示会话标题/成员/状态，中间是 `ListView` 消息流（bubble delegate），底部是 `Composer`（TextArea + actions） |
| 文件/通知 | `Drawer / Overlay` | 显示进行中的文件传输、历史通知、系统消息 |
| AI 区域 | `SwipeView` 或 `Expander` | 提供智能回复建议、AI 助手对话入口、图像标注结果 |
| 状态栏 | `StatusBar` 自定义控件 | 显示网络状态、文件进度、提示语 |

### 数据与交互

1. **会话管理**：
   - 新增 `QuickConversationListModel`（会话概览）与 `QuickMessageListModel`（消息详情），支持双向绑定。
   - `QuickAppHost` 记录当前会话 ID，暴露切换、清空、加载历史等接口。

2. **联系人/群组**：
   - `QuickContactListModel` 从 `SettingsContactRepository` 读取，支持搜索/分组过滤。
   - `QuickGroupListModel` 利用 `NetworkManager::groupMembersUpdated` 更新成员列表。

3. **动作入口**：
   - 文件：`Q_INVOKABLE sendFile()`/`acceptFile()`，结合 `FileDialog`。
   - AI：`invokeAI(action, payload)`，与 `IAIService`/`AIServiceFactory` 整合。
   - 状态：`updateStatus(status, text)`，调用 `NetworkManager::updateLocalUserStatus`。

4. **通知反馈**：
   - 沿用现有 `toastRequested`，并新增 `notificationPosted` 信号用于消息气泡和状态栏提示。

此布局草案将在实现阶段进一步细化尺寸、样式与交互。
