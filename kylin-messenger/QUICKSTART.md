## 系统要求

### 硬件要求

- **处理器**: 瑞芯微 RK3588/RK3576/RK3568 或兼容SoC
- **内存**: 至少 2GB RAM
- **存储**: 50MB 可用空间
- **网络**: 局域网连接

### 软件要求

- **操作系统**: 麒麟操作系统 (Debian-based)
- **Qt版本**: Qt 6.2 或更高
- **可选**: RKNN Runtime 2.0+（用于AI功能）

## 安装

### 方法1: 从DEB包安装（推荐）

```bash
# 下载DEB包
wget https://github.com/yourusername/kylin-messenger/releases/download/v1.0.0/kylin-messenger_1.0.0_arm64.deb

# 安装
sudo dpkg -i kylin-messenger_1.0.0_arm64.deb

# 解决依赖（如果有）
sudo apt -f install
```

### 方法2: 从源码构建

```bash
# 克隆仓库
git clone https://github.com/yourusername/kylin-messenger.git
cd kylin-messenger

# 安装依赖
sudo apt update
sudo apt install qt6-base-dev qt6-tools-dev cmake build-essential zlib1g-dev

# 构建
chmod +x build.sh
./build.sh

# 安装
./build.sh --install
```

## 首次运行

### 启动应用

**从应用菜单**:
1. 打开应用菜单
2. 找到"网络" → "麒麟信使"
3. 点击启动

**从终端**:
```bash
kylin-messenger
```

### 初始设置

首次运行时，应用会：

1. **自动获取用户信息**
   - 用户名默认为系统用户名
   - 可以在设置中修改

2. **初始化网络**
   - 自动检测本机IP地址
   - 开始监听UDP端口2425和TCP端口2426

3. **扫描局域网**
   - 自动发现同一网段内的其他用户
   - 在线用户会显示在用户列表中

## 基本使用

### 发送消息

**方法1: 双击用户**
1. 在主窗口用户列表中找到目标用户
2. 双击用户名
3. 在弹出的聊天窗口中输入消息
4. 按 `Enter` 或点击"发送"按钮

**方法2: 右键菜单**
1. 右键点击用户
2. 选择"发送消息"
3. 开始聊天

### 发送文件

**方法1: 通过工具栏**
1. 打开聊天窗口
2. 点击工具栏的"📁 文件"按钮
3. 选择要发送的文件
4. 等待传输完成

**方法2: 拖放**
1. 将文件拖到聊天窗口
2. 松开鼠标完成发送

### 发送截图

1. 点击工具栏的"📷 截图"按钮
2. 或按快捷键 `Ctrl+Alt+A`
3. 拖动鼠标选择区域
4. 截图自动发送到当前聊天

### 设置状态

在主窗口底部：

1. **状态下拉框**: 选择在线/离开/忙碌/隐身
2. **状态消息**: 输入自定义状态文本（如"开会中"）

## AI功能

### AI聊天助手

启动AI助手：

**方法1: 菜单**
1. 点击"工具" → "AI聊天助手"

**方法2: 工具栏**
1. 点击工具栏的"🤖 AI"按钮

**使用AI助手**:
```
用户: 请介绍一下你自己
AI: 我是麒麟信使的AI助手，基于NPU加速的本地大语言模型...

用户: 今天天气怎么样？
AI: 抱歉，我没有联网功能，无法获取天气信息...
```

### 智能回复建议

当收到消息时：

1. 聊天窗口底部会显示智能回复建议
2. 显示格式: `💡 智能回复: [好的] [明白了] [收到]`
3. 点击建议按钮快速回复

示例：
```
对方: 今天下午3点开会
智能回复: [好的，收到] [明白了] [我会准时参加]
```

### 图像智能标注

发送图片时：

1. AI自动分析图像内容
2. 在图片下方显示识别到的对象
3. 例如：`🏷️ 检测到: 电脑, 键盘, 鼠标`

### 内容过滤

系统自动检测：

- 不当内容会被标记
- 用户会收到警告提示
- 保护通信安全

## 故障排除

### 问题1: 看不到其他用户

**可能原因**:
- 网络未连接
- 防火墙阻止UDP/TCP端口
- 不在同一网段

**解决方法**:
```bash
# 检查网络
ping 192.168.1.1

# 检查防火墙
sudo ufw allow 2425/udp
sudo ufw allow 2426/tcp

# 重启应用
killall kylin-messenger
kylin-messenger
```

### 问题2: AI功能不可用

**可能原因**:
- RKNN运行时未安装
- AI模型文件缺失

**解决方法**:
```bash
# 检查RKNN运行时
ldconfig -p | grep rknn

# 如果未安装，安装RKNN Runtime
sudo apt install librknnrt

# 重启应用
```

### 问题3: 消息发送失败

**可能原因**:
- 对方已离线
- 网络连接中断

**解决方法**:
1. 检查用户状态（在线/离线）
2. 等待对方重新上线
3. 检查网络连接

### 问题4: 应用崩溃

**收集调试信息**:
```bash
# 查看日志
cat kylin-messenger.log

# 使用调试模式运行
kylin-messenger --debug

# 报告问题
# 访问: https://github.com/yourusername/kylin-messenger/issues
```
